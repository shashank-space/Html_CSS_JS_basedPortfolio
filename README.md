# Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website built using **HTML5**, **CSS3**, and **JavaScript**.

This project showcases frontend web development skills including responsive design, DOM manipulation, event handling, form validation, dark mode implementation, and local storage functionality.

Dark mode preference is saved locally using:

